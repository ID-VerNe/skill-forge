# agents

Subagent definitions (`agents/`) for Claude Code multi-agent orchestration. Each subagent is defined as a `.md` file with frontmatter specifying name, description, tools, and max turns.

## Subagents

Claude Code 子 agent 的定义和配置。

### glue-repo-architect
Deep single-repo architecture analysis. Reads source code, identifies modules, entry points, data flow, and external dependencies. Writes `architecture.md`, `architecture.json`, `source_manifest.json`, and `unresolved.md`.

### glue-reuse-mapper
Extracts reusable code candidates with license checks. Identifies functions, classes, and modules that can be extracted for reuse in the target project.

### glue-integration-planner
Integration route planning. Produces a comparison of fork vs compose vs build strategies for each candidate library.

### glue-synthesizer
Final user-facing recommendation synthesis. Reads all prior reports and produces a concise recommendation with rationale.

## Key Concepts

subagent 的主要协议：输出协议和配置。

### Output Protocol

Every subagent must:
1. Write full reports to disk (under `.glue/deep/`)
2. Return only a short summary to the main agent (< 10 lines)
3. Never paste full reports into the main conversation context

### Configuration

Each subagent definition includes:
- `max_turns` — Maximum conversation turns before forced completion
- `color` — Display color in Claude Code UI
- `tools` — Allowed tool set (Read, Write, Edit, Glob, Grep, Bash, etc.)
