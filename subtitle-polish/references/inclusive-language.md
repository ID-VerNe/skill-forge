# 第 8 类：中立与合规（性别·宗教·政治·法律）

本文件是 `category-taxonomy.md` 第 8 类的判据来源。但它**不再是闭集清单**——
见下一节「清单是起点，不是判据」。改词表仍然只改这一处。

## 清单是起点，不是判据

这一类最初是「闭集词表 + 脚本扫描」：清单外的候选一律不许进 `fixes.json`。
现在改成：**清单与正则只负责给线索，判断交给读上下文的审计 agent**。

理由只有一条，但它足够：

> **词表扫描的召回上限就是词表本身。** 用它当判据，等于宣称「清单里没有的
> 问题不存在」——这只在「问题真的只是词语替换」时成立。而这一类恰恰不是。

例子（同一个问题，词表一个都抓不到）：

| 该报的问题 | 为什么抓不到 |
|---|---|
| `the first time she's ever taken a boat out` 译成「她第一次带船出海」 | 表面没毛病，但这是隐喻，按本类判据该考虑「首航」；词表里只有 `处女航` |
| `mainland` 译成「中国本土」 | `大陆`/`内地` 都不出现 |
| `You drive like my sister` 译成「你开车像个娘们」 | `像个女人` 抓不到「像个娘们」这种措辞；而「我这妹妹开车一向稳」时又不该报 |
| 角色用地域/口音模仿开涮 | 一个敏感词都没有 |
| `passed away` 译成「他嗝屁了」 | 词表有 `死翘翘`，没有「嗝屁」 |

反方向的例子同样致命（词表抓到了，但按语境**不该改**）：

- `This is the Virgin Islands` → 「这是处女群岛」。词表命中，但那是地名，改了就错。
- `He's a real mother hen` → 「他像个老妈子」。性别刻板印象的味道取决于语境：
  角色在夸他细心还是在笑他。**同一条命中，两种结论。**

所以职责这么分：

| 谁 | 干什么 | 不干什么 |
|---|---|---|
| 脚本（`scan_seed.py` / `scan_inclusive.py`） | 出**锚点**：命中词、白名单候选、感叹/贬义/主权形态、上下文段 | 不判「是不是问题」，不给「该怎么改」 |
| 审计 subagent（并行，按切片分工） | **通读自己那一片**，逐条判 L1/L2/L3/不是问题，并给理由 | 不绕过白名单、不碰 C 子域 |
| 主 agent | 合并去重、白名单核对、门 1 交人裁 | 不替 subagent 判 |

三条配套约束（缺一条就退回闭集模式）：

1. **整片读完**。锚点只用于定位，不是待办清单。只看锚点 = 召回退化成词表。
2. **锚点之外可报，但必须写理由**：为什么这算问题 + 为什么现有形态没收它。
   后一条是给清单迭代用的——反复出现的新形态该沉淀进本文件。
3. **不是问题也要记**。锚点判「不是问题」的，写一行假阳记录（`false_positive`），
   否则清单只增不减，几轮之后会变成一堆没人敢删的噪声。

> 这一改动不降低误改风险，因为防误改的闸不在「脚本抓得准不准」，而在
> **白名单 + L3 只标 + C 子域零改 + 门 2 逐条确认**。那四道闸原样保留。

## 为什么需要独立一类

前 7 类的判据都是「译得对不对」。这一类判的是**另一种东西**：

> 这个译法本身没错，但会被人拿来指责。

- `处女航` —— 中文里常见译法，语义没问题。但 `处女` 被读作把「首次」绑定在女性身体隐喻上，
  挑刺者会据此说字幕性别歧视。同义的 `首航` 就在手边，没有任何损失。
- `天啊 / 老天` ← `God` —— 面向宗教敏感受众时是同类问题，改成 `天呐 / 哎呀` 音近而无声。
- `大陆`（指中国内地）→ `内地` —— 涉及国家主权表述，改一个词的成本几乎为零，
  不改则整片可能被判为表述不当。这类事**不是翻译质量问题，是合规问题**。
- `死了 / 挂了` ← `passed away` —— 死亡表达在中国传播环境里是软性（平台）管制而非法律禁止，
  同一个词在不同场景下的处置完全不同。

这类问题的**成本结构跟前 7 类相反**：漏改的代价是被人挑刺或踩合规（一次公关/下架问题），
**误改的代价是改坏语义、改掉角色设定、甚至把正确的行业词改坏**（`母头` 改成 `母端头`，
装配工看不懂；`the mainland` 指「美国本土」改成「内地」直接译错）。

所以本类的设计重心是**防误改**，不是找得全。

## 四个子域（与性别并列，不是附属）

| 子域 | 判的是 | 典型 | 处置倾向 |
|---|---|---|---|
| **A 性别与性** | 性别绑定、性化表述 | `处女航`、`像个女人` | 有等价替换就换，成本低 |
| **B 宗教与迷信** | 无谓的宗教冒犯 | `上帝啊`、`天杀的` | 看台词主题，宗教主题不改 |
| **C 政治与主权** | 主权表述、时政/民族/宗教/领土 | `大陆`、`台湾`、`西藏`、`新疆` | **零自动改**，全部交人裁 |
| **D 法律与其他** | 歧视性称谓、侮辱语、平台软性管制 | 种族/性向/地域/残障称谓、死亡/血腥/脏话 | 原文即贬义则只标；软性管制可换则换 |

子域只是**分类标签**，决定「默认给不给替换建议」和「归谁裁」；
L1–L4 四层处置对四个子域通用。

### C 子域为什么是「零自动改」

政治内容属于**判断问题、不是词语问题**：

1. 同一个词在不同语境下的安全译法不同（`mainland` 可能是「内地」，也可能是「美国本土」）；
2. 更安全的替换往往需要**重写整句**甚至补背景，超出「换词」的范围，也不是字幕该做的事；
3. 判错的后果不对称：改错一句时政表述的代价，远大于标注一句让人自己看。

所以 C 子域**永远进报告（作 `flag`），不进 `fixes.json`**，不论在 L1 还是 L2。
例外只有一类：**字幕自身表述错**（不是节目内容），且替换是纯粹的主权用语规范化
（`大陆`→`内地`、`台湾`→`中国台湾`）——也要显式 `--with-politics` 才落盘。

## 四层与处置

| 层 | 判据 | 处置 | 进 `fixes.json` |
|---|---|---|---|
| **L1 硬替换** | 词语本身即问题，替换后语义完全等同，无需看上下文 | 直接建议替换 | 是（`enabled: true`；C 子域需 `--with-politics`） |
| **L2 语境替换** | 需看原文与上下文才决定，默认按建议但可保留 | 生成建议，标 `needs_context` | 是（审计 agent 确认后；C 子域一律否） |
| **L3 弱化** | 原文本身即贬义/刻板（节目里真有人这么说） | **不改**，只标注 | 否，进报告 |
| **L4 白名单** | 看着像，但改了就是错 | **默认判「不是问题」**；agent 认为该改只能写 L3 给理由 | 否，报告单列「已白名单」 |

| 处女作 | 出道作 / 首部作品 | 按语境二选一，默认「首部作品」 |
| 处女秀 | 首秀 | |
| 处女地 | 未开发地区 / 处女地（慎） | 见下方 L2 增补说明：比喻义常需保留 |
| 处女座 | **（白名单，默认不改）** | 星座名，见 L4 |

**B 宗教与迷信**

| 命中 | 替换为 | 说明 |
|---|---|---|
| 耶稣基督啊 | 天呐 / 哎呀 | 感叹语，非宗教主题时改 |
| 我的老天爷 | 天呐 / 哎呀 | 感叹语 |
| 菩萨保佑 | 谢天谢地 | 仅在非信仰语境且原文是感叹时 |

**C 政治与主权**（只给替换词，**不构成自动改的授权**；需 `--with-politics` 才进 fixes）

| 命中 | 替换为 | 说明 |
|---|---|---|
| 中港台 | 中国内地、香港、台湾地区 | 表述规范化 |

| 台湾（单独作国家/地区对举） | 中国台湾 | 主权表述，须看整句；节目内容一律 flag |
| 西藏（政治对举时） | 中国西藏 | 同上，地名专名用法归白名单 |

**D 法律与其他**

| 命中 | 替换为 | 说明 |
|---|---|---|
| 基佬 / 玻璃（指同性恋，贬义） | 同性恋者 / 按语境重写 | 中性叙述时不改 |
| 残废（非自嘲、非原话） | 残障人士 | 原文即贬义则 L3 |
| 洋鬼子 | 外国人 | 歧视性称谓 |
| 死翘翘 | 去世 / 离世 | 仅严肃场景；动作片不改 |
| 死鬼（骂人） | 讨厌鬼 / 你这个人 | 玩笑语境保留 |

> 台词里明确谈论上帝/信仰时不改 —— 那是内容，不是口癖。

### L2 语境替换（需看英文原文）

| 中文形态 | 常见来源 | 默认建议 | 保留条件 |
|---|---|---|---|
| 天啊 / 老天啊 / 我的天啊 / 上帝啊 | God / My God / Oh my God | 天呐 / 天哪 | 台词主题就是宗教（教堂、牧师、信仰讨论）时保留 |
| 天杀的 / 该死的 | damn it / goddamn | 见鬼 / 糟糕 | 人物粗口是人物设定时保留（可仅弱化为「见鬼」） |
| 娘们 / 娘娘腔 / 像个女人 | like a girl / like a woman | 依语境改写为具体描述 | **原文即贬义时（角色在侮辱人）应保留原意**，只标注不硬改 |
| 女司机 / 女司机开车 | 无对应英文（中文自发添加） | 删掉「女」字 | 台词明确以性别为前提时保留 |
| 婆妈 / 婆婆妈妈 | fussy / nagging | 啰嗦 / 磨叽 | |
| 大陆 / mainland | the mainland | 内地 | **`the mainland` 可指「美国本土」「欧洲大陆」，原文是国名语境时才改**；判不准就 flag |
| 台湾 | Taiwan | 中国台湾 | 节目内容一律 flag，不改译文 |
| 老外 / 洋人 | foreigner | 外国人 | `洋鬼子` 即歧视，按 L1/L3 |
| 神经病 / 精神病（骂人） | crazy / psycho | 有病吧 / 疯了吧 | 医疗语境保留 |
| 土著 | native / indigenous | 原住民 | 学术语境保留 |

> L2 里 `大陆 / 台湾` 两行属于 **C 子域**，按上面「零自动改」处理：
> 默认只 flag，`--with-politics` 且语境明确时才落盘。

### L3 弱化（只标注）

英文原文本身就是歧视性表达（角色在骂人、在讲老笑话、在复述别人的偏见）时，
字幕的责任是**忠实**，不是替角色洗白。这些一律只标注：

- 原文含 `fag / retard / bitch / cunt / chink` 等侮辱词 → 译出原意，报告标注「原文含侮辱语」
- 原文把女性/少数族裔/残障者当笑料 → 照译，报告标注
- 角色口音/阶层歧视性模仿 → 照译
- 角色发表政治/宗教观点（含与我方立场相悖的内容）→ 照译，报告标注 `political-flag`

判据：**冒犯来自原文还是来自译法**。来自原文 → L3 只标；来自译法 → L1/L2 改。

### L4 白名单（默认不改）

默认判「不是问题」，不生成任何建议。这是本类最重要的部分（防误改的闸在这里，
不在「脚本抓得准不准」）。注意：**默认不改不是不许讨论**——agent 通读后若认为确实该改，
写 L3 并给理由，不要自行造替换词绕过白名单。

| 白名单词 | 为什么不能改 |
|---|---|
| 母头 / 公头 | 螺接、端子的**行业标准通用词**（female/male connector）。改成「母端头/阳接头」装配工反而不懂 |
| 母座 / 公座 | 同上，PCB 排针排母的通用叫法 |
| 母螺纹 / 公螺纹 | 机加工标准术语（female/male thread） |
| 母插 / 公插 | 接插件通用词 |
| 处女座 | 星座名（Virgo），`处女` 是专名一部分 |
| 处女星号 / 处女号 | 船名/车名/作品名里的字面专名 |
| 夫妻肺片 | 川菜名，专有菜名 |
| 处女地（比喻义） | "uncharted territory" 的常规译法，**改动会破坏比喻**；仅在明确指地理区域时考虑 |
| 大陆架 / 大陆坡 / 大陆性气候 | 地质地理术语，与主权表述无关 |
| 大陆（人名/作品名/企业名） | 专名的一部分 |
| 台湾卤肉饭 / 台湾地区 | 地名指称物与已规范表述，不是问题表述 |
| 西藏高原 / 西藏牦牛 | 地名专名用法 |
| 太平天国 / 义和团 | 表格/书名/专名 |

**白名单的维护原则**：只加不改。发现一个新的「看着像问题但其实是标准词」就加一条，
不要为了少一条报告就去改白名单里的既有条目。

## 五条硬约束

实施时**必须**满足，缺一条就退回。

1. **判断归 agent，不归脚本**：脚本给的是锚点，不是待办清单。agent 必须通读自己那一片，
   **锚点之外也可报**（写明理由）。反过来也不许「锚点有就报」——见第 2 条。
2. **白名单优先**：L4 命中默认判「不是问题」。agent 若认为某条真该改，只能写成 L3 并给理由，
   **不得自行生成替换词绕过白名单**。顺序反了，`母头` 会被当成 `母` 开头的问题词，
   `大陆架` 会被当成主权表述。
3. **改动须保留语义**：`处女航`→`首航` 语义等同，可改；`处女座`→`首座` 语义全毁，不可改。
   判断标准是「替换后中文读者得到的**事实**是否改变」。
4. **政治零自动改（C 子域）**：不论哪一层，C 子域的输出一律是 `flag`，**永不进 `fixes.json`**。
   唯一例外是字幕自身的主权用语错、替换只做规范化，且显式 `--with-politics`。
   政治内容超出字幕职责范围，交人裁是唯一安全解。
5. **来源可追溯**：本文件即来源，`updated_at` 见文件尾。**不引用外部词表**——
   外部词表（尤其英文世界的中性语言指南）常带预设立场，会把正常译法（`母头`、`处女座`）
   判成问题；反过来，**本 skill 也不承担时政立场判定**。

### 假阳也要记（清单才不会只增不减）

锚点判「不是问题」的，报告里写一行 `false_positive`：哪一行、命中什么形态、为什么不算问题。
没有这一项，清单会随着每次「宁可多列一个」越滚越大，最后变成没人敢删也没人看得完的噪声——
而真正的新形态（`Virgin Islands` 这种）反而被埋在里面。清理与新增同等重要。

### 不入清单原则

以下内容**故意不写进本文件**，以免把字幕工具做成政治审查工具，也避免词表引入争议性立场：

- 具体时政事件、人物、组织、运动的名称
- 民族、宗教、领土争议的具体表述判定（只保留「主权用语规范化」这一类可机械判定的）
- 任何需要「立场判断」才能决定改不改的内容

这些一律走 **C 子域 flag**：扫描只标「本行涉及时政/民族/宗教/领土表述」，
具体怎么处理由人决。设计目标是**发现 + 标注**，不是**判定 + 修改**。

## 与相邻类别的边界

| 情形 | 归哪类 | 理由 |
|---|---|---|
| `处女航` → 应为 `首航` | **第 8 类 A / L1** | 译法本身没问题，替换是风险规避 |
| `Get in!` 译成「进去」 | 第 4 类 | 语境错译，与敏感词无关 |
| 「这正是菲尔的强项」语序别扭 | 第 7 类 | 通顺度问题 |
| 台词里角色骂 `bitch` | **第 8 类 D / L3** | 只标注，不改译文 |
| 角色把车叫 `she` 译成「她」 | 第 8 类 A / L3 | 英文拟人化，照译；标注但不改 |
| `the mainland` 译成「大陆」 | **第 8 类 C** | 原文可指美国本土，判不准就 flag |
| 人名/地名拼错 | 第 5 类 | 拼写错，不是表述问题 |

**不确定时默认不改**。本类的默认动作是「记录 + 交人裁」，不是「自动修」。

## 扫描与线索

两条命令，职责不同，**都要跑**：

```bash
# 1) 线索：按切片出锚点 + 上下文段，输出直接贴进 subagent prompt 的 {seeds}
python <skill>/scripts/scan_seed.py .subtitle-polish/slices/<stem>_p1.txt \
    --out .subtitle-polish/reports/seed-<stem>_p1.json

# 2) 词表判定：出 L1/L2/L3 候选与白名单命中，给主 agent 合并时核对
python <skill>/scripts/scan_inclusive.py <ass_or_dir> --srt <srt_or_dir> \
    --json .subtitle-polish/reports/inclusive.json \
    --md .subtitle-polish/reports/inclusive-report.md
```

`scan_seed.py`（线索器）：

- 输入是**切片**（和 1–7 类共用同一批，不额外切一遍），也可直接吃 ASS。
- 锚点分五类形态：`lexicon` 词表命中 / `whitelist_hits` 白名单候选 /
  `interjection` 感叹起誓 / `derogatory` 贬义侮辱死亡 / `geo_political` 主权地域。
  后三类用独立正则，**故意扫得比词表宽**（`bloody hell`、`两岸`、`像个娘们` 都能命中）。
- 相邻锚点归并成**段**，每段带前后各 4 行上下文。subagent 按段读，
  因为「这句是角色在骂人还是复述别人的偏见」看一行判不出来。
- 退出码**不给「有无问题」信号**（恒 0）。拿它当门禁等于重新引入
  「词表没命中 = 干净」这个错误。

`scan_inclusive.py`（词表判定器）：

- **确定性、只读**：不调模型、不写 ASS、不改 log。
- 输出两组：`hits`（L1/L2/L3 候选，带建议）与 `whitelisted`（L4 命中，**明确写「已白名单，未改」**）。
  这里给的 `suggestion` 是**参考词**，不是定案——agent 判 L2 时要自己看英文与上下文。
- 每条 hit 带 `domain` 字段：`A` 性别与性 / `B` 宗教与迷信 / `C` 政治与主权 / `D` 法律与其他。
- `--domain C` 只跑政治与主权；`--layer L1` 只看硬替换层；`--politics` 允许 C 子域的 L1 出替换建议。
- 退出码：`0` 无候选；`1` 有候选（不是错误，是可操作信号）；`2` 输入非法。
  **它的 0 也不代表干净**——只代表词表没命中。

## 在轮次里的位置

第 8 类是 **R11 独立一轮**，默认不开启，显式 `--with-inclusive` 才跑。
**不并入 R10 收口轮**，理由：

1. 判据与前 7 类完全不同，混在收口轮里 agent 会在两种模式间切换，两头都判松；
2. 本轮产出的是「建议」而非「定案」（L3 只标、L4 不改、C 子域全 flag），跟收口轮的「定案」性质不同；
3. 独立成轮才能单独统计命中率与误改率，为清单本身的迭代提供分母。

R11 内部按子域分四段输出（A/B/C/D），**C 段只出 flag 表、不出改动表**。
C 子域的落盘需另外显式 `--with-politics`，且仍只能改「主权用语规范化」那一小类。

详见 `rounds-spec.md`。
